# dsh-webwhale-bili 0.2.0 方案

> 目标：把 0.1.x 的“进程内轮询 + 直接发送”改成“幂等入站 + 持久化出站 + 单例 worker + 可人工接管”的工作流运行时。

## 1. 0.2.0 要解决什么

0.1.x 的真实问题：

- 同一句话重复发
- 没有新消息也发
- 插件重载后内存状态丢失
- 多个轮询器同时存在
- 自己和对方的消息分不清
- 未知消息用固定兜底
- 禁用插件时还发睡前消息

0.2.0 不再增加“人格话术”，先修运行时。

## 2. 非目标

- 不接大模型自由生成
- 不自动关注
- 不自动发布视频/直播
- 不做无人值守 Windows 服务
- 不默认开启自动回复

## 3. 核心原则

```text
入站幂等
出站唯一
单例 worker
人工闸优先
未知不发送
失败不重试
```

## 4. 数据模型

### inbox

```text
account_id
talker_id
msg_id
at
text
state        received / ignored / queued / replied
created_at
PRIMARY KEY(account_id, talker_id, msg_id)
```

用途：同一条 B站消息只处理一次，重启不重复。

### outbox

```text
id
account_id
talker_id
msg_id
text
status       pending / sending / sent / failed / unknown
attempts
next_at
created_at
sent_at
error
UNIQUE(account_id, talker_id, msg_id)
```

用途：发送和业务分离；发送前还能限速、人工取消、审计。

### reply_state

沿用 0.1.x：

```text
lastInboundAt
lastOutboundAt
lastReplyText
lastReplyAt
lateDate
dayCount
```

## 5. 运行时状态机

```text
收到私信
  ↓
claim inbox（幂等）
  ↓ 已存在 → 退出
读取上下文 / 记忆 / 人格
  ↓
意图路由
  ↓ 未知 → ignored，不入 outbox
  ↓ 已知 → 生成候选回复
相关性 / 安全 / 重复校验
  ↓
enqueue outbox（唯一）
  ↓
sender worker
  ├─ 频率未到 → 保持 pending
  ├─ 通过 → 发送
  ├─ 成功 → sent + 记录
  ├─ 超时 → unknown，不重试
  └─ 明确失败 → failed
```

## 6. 单例与锁

- 全局只允许一个 auto-reply worker
- 全局只允许一个 lifecycle worker
- 每个 talker 同一时间只处理一个 run
- 插件 stop：
  - 清 timer
  - 停止新 claim
  - 正在发送的标 `unknown`
  - 不发睡前消息

## 7. 频率控制

```text
同一 msg_id：一次
同一轮：1 条
同一会话：20 分钟
同一句：30 分钟不重复
每天：3 条
```

## 8. 方向与身份

统一字段：

```text
account_id
talker_id
sender_id
direction
```

判断：

```text
sender_id === account_id → 自己
sender_id === talker_id  → 对方
```

UI 显示：

```text
我：……
对方：……
```

## 9. UI

- 私信会话只保留一个版块
- 显示方向
- 显示 outbox 待发/已发/失败
- 待审页显示 replyQueue
- 异常弹窗等 bootstrap 后再判断
- 不再使用任何演示数据

## 10. 迁移

从 0.1.x：

- 新增 `inbox` / `outbox` 表，`CREATE IF NOT EXISTS`
- 旧 `replyQueue` 保留
- 旧 `replyState` 字段缺失时用默认值
- JSON fallback 同步新增数组
- 不做破坏性迁移

## 11. 测试

必须覆盖：

1. 同一条消息 claim 两次 → 第二次 false
2. 重启后 claim 仍 false
3. 同一 msg_id enqueue 两次 → 只有一条
4. outbox pending 在重启后还在
5. 发送成功标 sent
6. 发送超时标 unknown，不自动重试
7. 自己发的消息不入站
8. 未知意图不入 outbox
9. 没有新消息不发
10. 插件 stop 不发消息
11. 多 worker 启动只保留一个
12. 前端无演示数据
13. `gate-check` 通过
