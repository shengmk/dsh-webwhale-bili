# 21 · 养鱼看视频（v0.2.22）

## 目标

用户主动给一条 B站视频链接，插件把「视频里讲了什么」整理成可读的中文总结。不是自动刷推荐流，也不是下载整站。

## 工作流

1. 解析 BV 号 / av 号 / b23.tv 短链；
2. 调 `x/web-interface/view` 拿标题、UP 主、分P、时长；
3. 调 `x/player/v2` 拿当前账号可见的字幕列表；逐条取回，选**覆盖到最晚且不超过视频时长**的轨（B站偶尔会把别的视频的长字幕混进列表，超过时长 +30s 的轨直接丢弃）；
4. 有字幕：下载字幕 JSON，按时间戳拼成转录；若末条时间明显短于视频时长（<80%），视为残字幕并回退 ASR；B站 AI 字幕若完全不含标题里的英文专名（如 DeepSeek），也视为错轨并回退 ASR；
5. 没字幕或字幕残缺：`yt-dlp` 下载音频，`faster-whisper` 本地转写（长视频用贪心解码，避免 CPU 上的 beam search 过慢）；
6. 把「标题 + UP 主 + 分P + 字幕来源 + 转录」交给 DeepSeek，按固定结构总结；
7. 结果写入 `video-summary/jobs.json`，转录写到 `video-summary/<job>.txt`；音频下载后删除。

总结结构固定为：一句话 / 核心内容 / 时间轴 / 关键结论或可执行步骤 / 适合谁看、注意。模型只被允许依据转录，不允许凭标题补内容。

## 可选依赖

```powershell
python -m pip install --user yt-dlp faster-whisper
```

- `yt-dlp`：没有字幕时下载音频；不登录也能拿 480P 音轨。
- `faster-whisper`：本地语音识别；首次用某个模型会从 Hugging Face 下载权重。
- `ffmpeg`：字幕/音频处理的外部依赖，通常在 PATH 里。
- 默认模型 `small`，可用环境变量 `WW_WHISPER_MODEL` 改成 `tiny`/`base`/`medium`。

插件不会自动执行 `pip install`，也不会静默下载大模型；卡片里只显示体检状态和安装提示。这样用户知道磁盘和网络什么时候被占用。

## 隐私与边界

- 字幕请求带当前账号 SESSDATA；cookie 只存在本机，不写日志、不进总结、不回显。
- 音频和转录只在本机临时目录/插件数据目录；任务完成后删除音频，保留转录文本供复查。
- 只处理用户主动提交的 URL；不自动遍历推荐、收藏夹、关注动态。
- 总结是「基于转录的整理」，不是视频画面理解；纯画面、无语音、无字幕的视频会明确失败，不编造。
- 转录可能有听错；总结提示词要求对不确定内容保持概括，不把猜测写成确定事实。
