# 0.2.1 评论链路

## 范围

```text
BV 白名单
→ 读取该视频评论
→ 跳过自己
→ inbox 幂等
→ 只处理最近 1 小时
→ 最多 2 条/轮
→ 分档
  ├─ 主人/互关低风险 → outbox comment
  ├─ 其他 → 待审
  └─ 风险/未知 → 忽略
→ sender 发评论
```

## 安全默认

```text
commentListen=false
autoReply=false
automationArmed=false
lifecycleMessages=false
```

三项都开启后才会真实评论。

## 白名单

设置 → 养鱼 →「评论 BV 白名单」：

```text
BV1GJ411x7h7
BV...
```

每行一个，最多 5 个。

## 自动发送边界

- 只对 **主人 / 互关**
- 只对低风险文本
- 同一会话 20 分钟冷却
- 每天 3 条
- 同句 30 分钟不重复
- 自己发的评论不入站
- 非白名单视频不处理

## 审核

非主人/互关评论：

```text
queueReply(source='comment')
```

进入「待审」，不自动发。

## 当前未验证

- 需要你提供真实 BV 白名单
- 需要真实评论（主人/互关）
- 评论发送 API 的真实回读

没有 BV 前不会开启 `commentListen`。
